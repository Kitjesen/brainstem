# 坐标系与关节

本文档定义 Thunder 机器人的坐标系约定、16 个关节的编号规则、运动范围和典型姿态。

---

## 1. 机体坐标系

Thunder 使用右手坐标系，原点位于机身几何中心：

```
              +Z (上)
               |
               |
               |
               +-------> +X (前)
              /
             /
            +Y (左)
```

| 轴 | 正方向 | 说明 |
|----|--------|------|
| X | 前方 (Forward) | 机器人头部方向 |
| Y | 左方 (Left) | 机器人左侧方向 |
| Z | 上方 (Up) | 垂直向上 |

### 正面视图

```
               +Z
                |
        FL      |      FR
    +---+-------+-------+---+
    |   |       |       |   |
    |   |     body      |   |
    |   |       |       |   |
    +---+-------+-------+---+
        RL      |      RR
                |
         +Y <--+
```

### 侧面视图（右侧）

```
         +Z
          |           前进方向 --->
          |
          +------ body ------+
          |                  |
         Hip               Hip
          |                  |
        Thigh             Thigh
          |                  |
        Calf              Calf
          |                  |
        [Foot]           [Foot]
    ----地面-----------------------
          |
          +-------> +X (前)

    后腿 (RR)           前腿 (FR)
```

### walk() 指令与坐标系的关系

| 参数 | 正值 | 负值 | 对应轴 |
|------|------|------|--------|
| `vx` | 前进 | 后退 | +X / -X |
| `vy` | 向左 | 向右 | +Y / -Y |
| `vyaw` | 逆时针 | 顺时针 | 绕 +Z 轴 |

## 4. 典型姿态

### 4.1 站立姿态 (Standing Pose)

站立姿态是机器人正常直立时各关节的目标角度：

```python
standing_pose = [
    -0.1, -0.8,  1.8,  0,    # FR: hip, thigh, calf, foot
     0.1,  0.8, -1.8,  0,    # FL: hip, thigh, calf, foot
     0.1,  0.8, -1.8,  0,    # RR: hip, thigh, calf, foot
    -0.1, -0.8,  1.8,  0,    # RL: hip, thigh, calf, foot
]
```

各关节含义：

| 关节 | FR 值 | 含义 |
|------|-------|------|
| Hip | -0.1 rad (-5.7 deg) | 微微内收，保持稳定 |
| Thigh | -0.8 rad (-45.8 deg) | 大腿向后摆约 46 度 |
| Calf | 1.8 rad (103.1 deg) | 小腿弯曲约 103 度 |
| Foot | 0 rad | 脚轮不转 |

> 注意左右对称：FR 和 RL 的符号相同，FL 和 RR 的符号相同（镜像关系）。

### 4.2 坐下姿态 (Sitting Pose)

坐下姿态即电机零位，所有关节角度为 0：

```python
sitting_pose = [0, 0, 0, 0,   # FR
                0, 0, 0, 0,   # FL
                0, 0, 0, 0,   # RR
                0, 0, 0, 0]   # RL
```

这是机器人趴在地面上的姿态，也是电机标零后的参考位。

### 4.3 姿态可视化

```
站立 (Standing)                  坐下 (Sitting / Zero)

    +-------+                        +-------+
    |  body |                        |  body |
    +--+-+--+                        +--+-+--+
       | |                             /   \
      /   \                           /     \
     /     \                      ---/-------\---
    /       \                        (地面)
   |         |
   |         |
  (o)       (o)
---地面-----------
```

## 5. PD 控制参数

每个关节的运动由 PD 控制器驱动：

```
torque = Kp * (target_pos - current_pos) + Kd * (target_vel - current_vel)
```

PD 增益参数（Kp/Kd）由用户在 Profile JSON 文件中配置，不同的运动策略可以使用不同的增益组合。详见 `profile_schema.json`。

`actionScale` 是 RL 策略输出到实际弧度的缩放系数，同样在 Profile 中配置。策略输出值经过以下变换得到目标关节角度：

```
target_position = action_output * actionScale + standingPose
```

## 6. 关节速度缩放

IMU 陀螺仪和关节速度在输入观测向量前会进行缩放：

| 参数 | 缩放系数 | 说明 |
|------|----------|------|
| `imuGyroscopeScale` | 0.25 | IMU 陀螺仪数据缩放 |
| `jointVelocityScale` | [0.05, 0.05, 0.05, 0.05] | 各类型关节速度缩放 |

## 7. 编程中的关节操作

### 7.1 读取关节数据

```python
# 实时流式读取
for joint in dog.listen_joint():
    print(f"关节 {joint.id}: "
          f"位置={joint.position:.3f}rad "
          f"速度={joint.velocity:.3f}rad/s "
          f"力矩={joint.torque:.2f}Nm")
```

### 7.2 诊断单条腿

```python
# 检查前右腿 (FR) 的 4 个电机
motors = dog.get_motor_status()
fr_motors = [m for m in motors if m.id in [0, 1, 2, 3]]
for m in fr_motors:
    print(f"  关节{m.id}: online={m.online} temp={m.temperature:.1f}C")
```

### 7.3 清除单腿故障

```python
# 只清除前右腿的电机故障
dog.clear_motor_fault(joint_ids=[0, 1, 2, 3])
```
