主控板负责：

- IMU 数据采集与融合
- CAN 总线电机通信
- 低压保护与安全监控

## 4. 关节与执行器

### 4.1 关节布局

Thunder 共有 **16 个自由度**，分为 4 条腿，每条腿包含 3 个旋转关节和 1 个脚轮：

```
        前 (Front)
   FL +---------+ FR
      |         |
      |  body   |
      |         |
   RL +---------+ RR
        后 (Rear)

每条腿的关节（由近到远）:
  Hip   -- 髋关节（横滚方向，内外摆动）
  Thigh -- 大腿关节（俯仰方向，前后摆动）
  Calf  -- 小腿关节（俯仰方向，前后摆动）
  Foot  -- 脚轮（连续旋转，轮式驱动）
```

### 4.2 电机规格

| 参数 | 腿部关节 (Hip/Thigh/Calf) | 脚轮 (Foot) |
|------|---------------------------|-------------|
| 电机 | Robstride | Robstride |
| 总线 | PCAN CAN | PCAN CAN |
| 最大力矩 | 50 Nm | 30 Nm |
| 控制模式 | PD 位置控制 | 速度控制 (Kp=0) |
| 反馈 | 位置 / 速度 / 力矩 / 温度 | 位置 / 速度 / 力矩 / 温度 |

### 4.3 PD 控制参数（default 策略）

行走推理阶段的 PD 增益：

| 关节类型 | Kp | Kd | 动作缩放 |
|----------|-----|-----|----------|
| Hip (髋) | 80 | 10 | 0.15 |
| Thigh (大腿) | 100 | 10 | 0.25 |
| Calf (小腿) | 120 | 15 | 0.25 |
| Foot (脚轮) | 0 | 1 | 5.0 |

> 脚轮的 Kp=0 表示不做位置控制，仅通过速度指令驱动。

站起/坐下阶段使用更高的刚度：Kp=200, Kd=8（全部 16 个关节统一）。

## 5. 传感器

### 5.1 惯性测量单元 (IMU)

| 参数 | 规格 |
|------|------|
| 型号 | HI91 |
| 数据 | 三轴陀螺仪 + 四元数姿态 |
| 频率 | ~50Hz |
| 安装位置 | 机身中央 |
| 坐标系 | x=前, y=左, z=上 |

IMU 提供两类数据：
- **陀螺仪** (`gyroscope`): 三轴角速度 (rad/s)，用于步态平衡
- **四元数** (`quaternion`): 当前姿态 (w,x,y,z Hamilton 约定)，用于重力投影

SDK 获取方式：

```python
for imu in dog.listen_imu():
    print(f"陀螺仪: x={imu.gyroscope.x:.3f} y={imu.gyroscope.y:.3f} z={imu.gyroscope.z:.3f}")
    print(f"姿态:   w={imu.quaternion.w:.3f} x={imu.quaternion.x:.3f}")
```

### 5.2 关节编码器

每个电机内置编码器，提供：

| 数据 | 单位 | 说明 |
|------|------|------|
| 位置 (position) | rad | 当前关节角度 |
| 速度 (velocity) | rad/s | 当前关节角速度 |
| 力矩 (torque) | Nm | 当前输出力矩 |

SDK 获取方式：

```python
for joint in dog.listen_joint():
    print(f"关节{joint.id}: pos={joint.position:.3f}rad vel={joint.velocity:.3f}rad/s")
```

### 5.3 总线电压

通过 CAN 总线读取电机端电压，反映电池状态：

```python
voltages = dog.get_voltage()  # 返回 16 个电机的电压值 (V)
avg = sum(voltages) / len(voltages)
print(f"平均电压: {avg:.1f}V")
```

## 6. 通信接口

### 6.1 接口一览

| 接口 | 协议 | 用途 | 方向 |
|------|------|------|------|
| 以太网 | gRPC (HTTP/2) | SDK 远程控制 | 双向 |
| PCAN CAN | CAN 2.0B | 电机指令/反馈 | 双向 |
| SBUS 串口 | SBUS | YUNZHUO 遥控器 | 输入 |
| USB | HID | Xbox 手柄 (备选) | 输入 |
| 串口 | UART | HI91 IMU | 输入 |

### 6.2 gRPC 服务

| 参数 | 值 |
|------|-----|
| 端口 | 13145 |
| 协议 | gRPC (Protobuf) |
| 加密 | 无（局域网内使用） |
| 服务名 | CMS (Central Motor System) |

gRPC 提供的 RPC 接口：

| 类别 | 方法 | 说明 |
|------|------|------|
| 电机控制 | `Enable` / `Disable` | 使能/禁用电机 |
| 运动指令 | `Walk` / `StandUp` / `SitDown` | 状态机动作 |
| 状态查询 | `GetCmsState` / `GetVoltage` / `GetMotorStatus` | 读取当前状态 |
| 策略管理 | `GetProfile` / `SwitchProfile` | 切换运动策略 |
| 诊断 | `ClearMotorFault` / `SetZero` | 清错/标零 |
| 数据流 | `ListenImu` / `ListenJoint` / `ListenCmsState` | 实时推送 |

### 6.3 控制器输入

Thunder 支持两种物理控制器，均通过 `ControlArbiter` 仲裁控制权：

| 控制器 | 接口 | 优先级 | 说明 |
|--------|------|--------|------|
| YUNZHUO 遥控器 | SBUS 串口 | 高 | 硬件遥控，最高优先级 |
| Xbox 手柄 | USB HID | 高 | Linux Joystick FFI 读取 |
| SDK (gRPC) | 以太网 | 低 | 被遥控器/手柄抢占 |

> 遥控器/手柄信号到达时立即抢占 SDK 控制权。遥控器松开 3 秒后自动释放控制权回 SDK。

## 7. 电源与电池

| 参数 | 值 |
|------|-----|
| 供电 | 锂电池组 |
| 工作电压范围 | [TODO: 确认满电电压] ~ 42V |
| 低压保护阈值 | **42V** |
| 低压保护行为 | 自动坐下 (graceful sit down) |

低压保护流程：
1. 控制循环每帧检测所有电机总线电压
2. 当最低电压 < 42V 时触发保护
3. 机器人自动执行坐下动作
4. 等待完全坐稳（Grounded 状态）后才禁用电机
5. 不会直接断电，确保安全着地

## 8. 控制频率

| 环节 | 频率 | 周期 |
|------|------|------|
| 主控制循环 | 50 Hz | 20 ms |
| ONNX 推理 | 50 Hz | 20 ms（每帧一次） |
| IMU 采样 | ~50 Hz | ~20 ms |
| CAN 电机通信 | 50 Hz | 20 ms |
| gRPC 状态推送 | 50 Hz | 20 ms |

整个控制链路在 20ms 的时间窗口内完成：

```
IMU采样 -> 构建观测 -> ONNX推理 -> PD计算 -> CAN发送 -> 电机执行
                        |
                  全部在 20ms 内完成
```
